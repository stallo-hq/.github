# Contributing

Read the [Engineering Handbook](https://github.com/stallo-hq/.github/blob/main/HANDBOOK.md) first. In short:

1. Pick up or create an issue, and assign it to yourself.
2. Branch from `main`: `<type>/<issue#>-<short-name>`.
3. Use Conventional Commits (`feat(orders): ...`).
4. Open a PR that links the issue and fills in the template. CODEOWNERS requests the right reviewer.
5. Get one approval and green CI, then squash and merge.
