# Stallo

WhatsApp commerce for small sellers. Customers order in chat, and Stallo handles orders, payments, delivery and daily summaries.

- **[stallo-api](https://github.com/stallo-hq/stallo-api)**: FastAPI backend, workers, orchestration
- **[stallo-web](https://github.com/stallo-hq/stallo-web)**: seller dashboard (React)
- **[Engineering handbook](https://github.com/stallo-hq/.github/blob/main/HANDBOOK.md)**: roles, ownership, workflow
